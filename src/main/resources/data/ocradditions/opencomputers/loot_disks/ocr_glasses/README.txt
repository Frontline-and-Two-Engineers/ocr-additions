OCR Additions - Smart Glasses Test Suite
========================================
1. Right-click a Glasses Bridge block with Smart Glasses to bind them, then wear them.
2. Run 'install' in OpenOS or execute scripts directly from <disk>/usr/bin/:

- glasses_t1 : Tier 1 2D HUD test (rects, text, icon, progress bar, anchors)
- glasses_t2 : Tier 2 chat prefix ($$), clickable HUD [H], live graph
- glasses_t3 : Tier 3 3D AR overlay, gaze raycast [G], wearer telemetry
- ar_radar   : Combined Radar + Smart Glasses AR entity highlight & graph

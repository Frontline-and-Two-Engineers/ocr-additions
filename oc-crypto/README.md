# OCCoin — Криптовалюта для OpenComputers

Децентрализованно-криптографическая система с **одним центральным хостом** и **клиентскими кошельками**, работающая исключительно на стандартных возможностях **OpenComputers** (без внешних модов и интернета):
- **Data Card (Tier 3)** — генерация ключей **ECDSA-256**, подпись и проверка транзакций, хеширование **SHA-256**, Base64.
- **Wireless Network Card** — беспроводное общение клиентов с хостом (автопоиск через `broadcast` + прямые пакеты на порт `4422`).
- **GPU + Screen** — графический интерфейс панели хоста и клиентского кошелька (поддержка клавиатуры и кликов мышью).

---

## Структура

- [lib/occoin.lua](lib/occoin.lua) — общая библиотека криптографии, протокола и GPU-UI.
- [client/wallet.lua](client/wallet.lua) — клиентская часть с кошельком (`/home/occoin_wallet.dat`), мульти-GPU CUDA-майнером (с откатом на Data Card) и журналом событий на экране. Также встроена в мод как некрафтящаяся дискета **`OCCoin Wallet`** (`occoin_wallet`).
- Серверная часть (хост) вынесена отдельно в игнорируемую git папку `occoin-host/` (`host.lua` + `lib/occoin.lua`).

---

## Требуемые компоненты в OpenComputers

### Для Хоста (Сервера)
1. **Computer Case / Server Rack** (OpenOS на HDD)
2. **Data Card (Tier 3)** — обязательна для `ecdsa`, `generateKeyPair`, `sha256`
3. **Wireless Network Card (Tier 1 или Tier 2)** — чем выше уровень, тем больше радиус связи
4. **GPU (Tier 2 или Tier 3)** + **Screen (Tier 2 или Tier 3)** + **Keyboard**

### Для Клиента (Кошелька)
1. **Computer / Tablet** (OpenOS на HDD) — *отлично работает и на планшетах (Tablet) с Data Card Tier 3 и Wireless Card!*
2. **Data Card (Tier 3)**
3. **Wireless Network Card**
4. **GPU + Screen + Keyboard**

## Установка и запуск

Скопируйте папку `oc-crypto` в `/home/oc-crypto` на компьютерах в OpenComputers (или через папку сохранения мира `saves/<мир>/opencomputers/<uuid>/home/oc-crypto`).

### 1. Запуск Хоста
На сервере выполните:
```lua
/home/oc-crypto/host/host.lua
```
Управление на хосте:
- `M` — выпустить монеты (Mint) на указанный адрес `OCC-...` (для первичной раздачи)
- `+` / `-` — изменить сложность майнинга (`1..6` ведущих нулей SHA-256)
- `S` — принудительно сохранить реестр на диск
- `Q` — сохранить и остановить сервер

### 2. Запуск Клиента (Кошелька)
На клиенте (компьютере или планшете) выполните:
```lua
/home/oc-crypto/client/wallet.lua
```
При первом запуске автоматически сгенерируется пара ключей ECDSA-256 и адрес вида `OCC-xxxxxxxxxxxxxxxxxxxxxxxx`, а также выполнится поиск хоста по беспроводной сети.

Управление в кошельке (клавиатурой или кликом по строке):
- `R` — обновить баланс и историю
- `S` — отправить монеты (подписывается локальным приватным ключом на Data Card)
- `H` — история транзакций (`O` — вернуться назад)
- `M` — майнинг блока через `SHA-256` на Data Card (награда `10 OCC`)
- `F` — повторный поиск хоста по беспроводной сети
- `Q` — выход

## Как обеспечивается безопасность

1. **Цифровая подпись (ECDSA-256):** приватный ключ никогда не покидает клиент. На хост отправляется только публичный ключ, подпись и данные транзакции.
2. **Защита от повторного воспроизведения (Replay Attack):** каждая транзакция содержит `nonce`, который хост проверяет и инкрементирует после каждого перевода. Перехват беспроводного пакета не позволит злоумышленнику повторить перевод.
3. **Хеш-цепь блоков:** каждая операция (`GENESIS`, `MINT`, `TX`, `MINE`) связывается через `SHA-256` с хешем предыдущего блока.

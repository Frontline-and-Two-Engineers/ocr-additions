# OCR Additions — Документация

**OCR Additions** — аддон для **OpenComputers Rebooted** (Minecraft 1.21.1 / NeoForge), добавляющий **умные очки трёх уровней** (с периферийным мостом `glasses_bridge`) и **радары трёх уровней**.

## Устройства и уровни

### Умные очки и Мост умных очков (`ocradditions:glasses_bridge`)

| Предмет / ID | Уровень | Возможности |
| :--- | :---: | :--- |
| `ocradditions:smart_glasses_tier_1` | **Tier 1** | Простой 2D HUD-оверлей: прямоугольники, текст, прогресс-бары, иконки предметов, якоря экрана (`Anchor`). |
| `ocradditions:smart_glasses_tier_2` | **Tier 2** | Всё из Tier 1 + **графики** (`addGraph`), **интерактивный кликабельный HUD** (клавиша `H`), **чат-команды по префиксу** (по умолчанию `$$`, настраивается через API). |
| `ocradditions:smart_glasses_tier_3` | **Tier 3** | Всё из Tier 1 и Tier 2 + **3D AR-оверлей** (точки, линии в мире, маркеры сущностей), **отслеживание взгляда** (клавиша `G`), **телеметрия носителя** (`getPlayerStats`). |

> Сервер автоматически фильтрует виджеты и события под уровень надетых игроком очков: например, на очках Tier 1 не отображаются графики и 3D-маркеры и не перехватываются сообщения с префиксом.

### Радары (компонент OpenComputers `radar`)

| Блок / ID | Уровень | Радиус | Возвращаемые данные |
| :--- | :---: | :---: | :--- |
| `ocradditions:radar_tier_1` | **Tier 1** | `64` блока | `type` |
| `ocradditions:radar_tier_2` | **Tier 2** | `128` блоков | `type`, `distance` |
| `ocradditions:radar_tier_3` | **Tier 3** | `256` блоков | `type`, `name` (ник игрока для `Player`), `isPlayer`, `distance`, относительные `x`, `y`, `z`, `uuid` |

## Быстрый старт

1. Поставьте блок **`Мост умных очков`** (`ocradditions:glasses_bridge`) и подключите его к компьютеру OpenComputers Rebooted (вплотную или через кабель). В ОС он появится как компонент `glasses_bridge`.
2. Возьмите любые **Умные очки** в руку и нажмите **ПКМ по Мосту умных очков** — очки привяжутся к UUID этого моста (`bridgeId`).
3. Наденьте очки в слот шлема (или в слот `head` мода **Curios**, если он установлен). При нажатии ПКМ по воздуху очки также надеваются.
4. *(Опционально)* Подключите любой **Радар** (`radar_tier_1..3`) к компьютеру — он появится как компонент `radar`. Любой блок радара также можно вставить напрямую как **апгрейд (`Slot.Upgrade`)** в **Планшет, Робота или Дрона** (уровень требуемого слота соответствует уровню радара: Tier 1..3), получая мобильный радар в движении.
5. *(Опционально)* Для расширения зоны действия моста используйте стандартные **Ретрансляторы OpenComputers (`Relay`)**:
   - **Проводом:** подключите `Relay` с беспроводной сетевой картой (Tier 1 / Tier 2) к сети моста.
   - **По воздуху (без проводов к дальним ретрансляторам):** от проводного `Relay` или **беспроводной сетевой карты (`Wireless Network Card`)** в компьютере сигнал автоматически доходит по цепочке до автономных `Relay` с включённым режимом ретрансляции (`isRepeater`).
   - **Через Linked Card:** два `Relay` со связанными картами передают сигнал напрямую на любое расстояние (включая другие измерения при `repeaterAllowCrossDimension = true`).
   - Другие мосты `glasses_bridge` сигнал чужих мостов не ретранслируют.

> Подсказка: ПКМ с пустой рукой по блоку `glasses_bridge` показывает в action-bar короткий ID моста и текущий префикс чата.

## Относительные координаты

По умолчанию (`relativeCoordinates = true` в конфиге):
- Для **`glasses_bridge`**: начало координат `(0, 0, 0)` — это сам блок `glasses_bridge` (`worldPosition`). Все 3D-маркеры (`addWorldMarker`, `addWorldLine`), координаты взгляда (`blockX/Y/Z`, `hitX/Y/Z`), позиция носителя (`getConnectedPlayers`, `getPlayerStats`) рассчитываются **относительно блока моста**.
- Для **`radar` (Tier 3)**: координаты `x, y, z` каждой найденной сущности рассчитываются **относительно блока радара** (`entityPos - radarBlockPos`).

## Горячие клавиши и экипировка

| Клавиша (по умолчанию) | Ключ локализации | Действие |
| :---: | :--- | :--- |
| **`H`** | `key.ocradditions.cursor` | Открывает экран курсора для клика по виджетам с `clickable = true` (Tier 2+). |
| **`G`** | `key.ocradditions.gaze` | Отправляет луч взгляда до 64 блоков: блок, сущность или промах (Tier 3). |

## Конфигурация

Файл `config/ocradditions-common.toml` создаётся NeoForge автоматически. Параметры по умолчанию из `Config.java`:

| Ключ | По умолчанию | Описание |
| :--- | :---: | :--- |
| `relativeCoordinates` | `true` | Использовать относительные координаты от моста/радара вместо мировых. |
| `defaultChatPrefix` | `"$$"` | Префикс чат-команд по умолчанию (1..16 символов без пробелов). |
| `maxRange` | `256` | Максимальная дистанция связи очков с мостом (`0` — без ограничения). |
| `allowCrossDimension` | `false` | Разрешить работу очков в другом измерении (требует `maxRange = 0` или того же измерения). |
| `repeaterRange` | `0` | Радиус покрытия вокруг каждого ретранслятора OpenComputers (`Relay`) в сети моста (`0` — использовать дальность беспроводной карты внутри ретранслятора, `> 0` — фиксированный радиус). |
| `repeaterAllowCrossDimension` | `false` | Разрешить ретрансляторам OpenComputers из другого измерения передавать сигнал на мост. |
| `requireEnergy` | `false` | Если `true`, очки требуют FE-энергию для работы и рендера. |
| `energyCapacity` | `100000` | Максимальный запас FE в очках. |
| `energyPerTick` | `5` | Расход FE за тик при активном подключении (`requireEnergy = true`). |
| `radarScanEnergyCost` | `0.0` | Расход энергии сети OpenComputers за один вызов `radar.scan()`. |
| `gpuComputeEnabled` | `true` | Включает CUDA-вычисления на видеокартах и APU OpenComputers. |
| `gpuComputeWorkerThreads` | `0` | Потоков пула GPU (`0` = авто: половина ядер CPU, макс. `4`). |
| `gpuComputeDutyCycle` | `0.50` | Макс. рабочий цикл потоков (`0.05..1.0`) для защиты TPS сервера. |
| `gpuComputeMaxJobsPerCard` | `4` | Макс. число активных/ожидающих задач на одну GPU. |
| `gpuComputeMaxGlobalQueue` | `128` | Макс. число задач в очереди на всём сервере. |
| `gpuComputeEnergyPerOp` | `0.01` | Расход энергии сети OC за хэш/операцию. |
| `gpuComputeMaxOutputRows` | `16384` | Макс. число строк результата на одну задачу. |
| `[gpuTier1]` .. `[gpuTier4]` | — | Настройка `cudaCores`, `maxBatchSize`, `maxArrayElements`, `pacingMsPer4kOps` для каждого тира GPU. |

## Тестовые дискеты OpenComputers

В аддон встроены 3 готовые датапак-дискеты (`data/ocradditions/opencomputers/loot_disks/`), доступные в креативной вкладке **OpenComputers** и через циклический крафт дискет (`recipe_cycling = true`):

1. **`OCR Glasses Tests`** (`ocr_glasses`, голубая): `glasses_t1`, `glasses_t2`, `glasses_t3`, `ar_radar`
2. **`OCR Radar Tests`** (`ocr_radar`, лаймовая): `radar_test`, `radar_watch`
3. **`OCR CUDA Tests`** (`ocr_cuda`, оранжевая): `cuda_bench`, `crypto_miner`

Также в мод встроена дискета (без циклического крафта `recipe_cycling = false`, `weight = 0`), которая крафтится из **Дискеты (`opencomputers:floppy`) + Алмазной кирки + Видеокарты (Tier 1–4)**:

4. **`OCCoin Wallet`** (`occoin_wallet`, лаймовая): `occoin_wallet` + библиотека `occoin` (`/usr/lib/occoin.lua`)

Вставьте дискету в дисковод OpenOS и выполните `install` (установит программы в `/usr/bin/`), либо запускайте напрямую из `/mnt/<метка_диска>/usr/bin/<программа>.lua`.

## Криптовалюта OCCoin (`OCCoin Wallet`)

Клиентский кошелёк и майнер для OpenComputers, работающий по беспроводной сети с центральным хостом:

- **Криптография на Data Card (Tier 3):** генерация ключей **ECDSA-256**, подпись и проверка транзакций, адреса формата `OCC-<24 hex от sha256>`, защита от повторного воспроизведения (`nonce`).
- **Беспроводное взаимодействие:** автопоиск хоста (`modem.broadcast` на порту `4422`), запрос баланса и истории, отправка подписанных переводов, получение уведомлений `NEW_BLOCK` в реальном времени.
- **Мульти-GPU майнинг:** автоматическое использование всех установленных видеокарт (`component.list("gpu")`) через CUDA-ядра (`compileKernel` / `runKernel`) с мгновенным переключением всех карт на следующий блок по событию `NEW_BLOCK` и автоматическим откатом на `Data Card (sha256)`, если GPU не поддерживают CUDA.
- **Интерфейс GPU + Screen (рекомендуется Tier 2/3):** управление клавиатурой и мышью (`touch`), а также встроенная панель **«Журнал (Банк / Майнинг)»** на экране с записью найденных блоков, сетевых обновлений и ошибок банка.

**Требования к клиенту:** Data Card (Tier 3), Wireless Network Card (Tier 1/2), GPU + Screen (рекомендуется Tier 2/3), HDD с OpenOS. Подробнее в [`oc-crypto/README.md`](../oc-crypto/README.md).

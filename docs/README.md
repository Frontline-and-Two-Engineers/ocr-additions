# OCR Additions — Документация

**OCR Additions** — аддон для **OpenComputers Rebooted** (Minecraft 1.21.1 / NeoForge), добавляющий **умные очки трёх уровней** (с периферийным мостом `glasses_bridge`) и **радары трёх уровней**.

## Устройства и уровни

### Умные очки и Мост умных очков (`ocradditions:glasses_bridge`)

| Предмет / ID | Уровень | Возможности |
| :--- | :---: | :--- |
| `ocradditions:smart_glasses_tier_1` | **Tier 1** | Простой 2D HUD-оверлей: прямоугольники, текст, прогресс-бары, иконки предметов, якоря экрана (`Anchor`). |
| `ocradditions:smart_glasses_tier_2` | **Tier 2** | Всё из Tier 1 + **графики** (`addGraph`), **интерактивный кликабельный HUD** (клавиша `H`), **чат-команды по префиксу** (по умолчанию `$$`, настраивается через API). |
| `ocradditions:smart_glasses_tier_3` | **Tier 3** | Всё из Tier 1 и Tier 2 + **3D AR-оверлей** (точки, линии в мире, маркеры сущностей), **отслеживание взгляда** (клавиша `G`), **телеметрия носителя** (`getPlayerStats`). |

> Сервер автоматически фильтрует виджеты и события под уровень надетых игроком очков: например, на очках Tier 1 не отображаются графики и 3D-маркеры и не перехватываются сообщения с префиксом.

### Радары (компонент OpenComputers `radar`)

| Блок / ID | Уровень | Радиус | Возвращаемые данные |
| :--- | :---: | :---: | :--- |
| `ocradditions:radar_tier_1` | **Tier 1** | `64` блока | `type` |
| `ocradditions:radar_tier_2` | **Tier 2** | `128` блоков | `type`, `distance` |
| `ocradditions:radar_tier_3` | **Tier 3** | `256` блоков | `type`, `name` (ник игрока для `Player`), `isPlayer`, `distance`, относительные `x`, `y`, `z`, `uuid` |

## Быстрый старт

1. Поставьте блок **`Мост умных очков`** (`ocradditions:glasses_bridge`) и подключите его к компьютеру OpenComputers Rebooted (вплотную или через кабель). В ОС он появится как компонент `glasses_bridge`.
2. Возьмите любые **Умные очки** в руку и нажмите **ПКМ по Мосту умных очков** — очки привяжутся к UUID этого моста (`bridgeId`).
3. Наденьте очки в слот шлема (или в слот `head` мода **Curios**, если он установлен). При нажатии ПКМ по воздуху очки также надеваются.
4. *(Опционально)* Подключите любой **Радар** (`radar_tier_1..3`) к компьютеру — он появится как компонент `radar`.

> Подсказка: ПКМ с пустой рукой по блоку `glasses_bridge` показывает в action-bar короткий ID моста и текущий префикс чата.

## Относительные координаты

По умолчанию (`relativeCoordinates = true` в конфиге):
- Для **`glasses_bridge`**: начало координат `(0, 0, 0)` — это сам блок `glasses_bridge` (`worldPosition`). Все 3D-маркеры (`addWorldMarker`, `addWorldLine`), координаты взгляда (`blockX/Y/Z`, `hitX/Y/Z`), позиция носителя (`getConnectedPlayers`, `getPlayerStats`) рассчитываются **относительно блока моста**.
- Для **`radar` (Tier 3)**: координаты `x, y, z` каждой найденной сущности рассчитываются **относительно блока радара** (`entityPos - radarBlockPos`).

## Горячие клавиши и экипировка

| Клавиша (по умолчанию) | Ключ локализации | Действие |
| :---: | :--- | :--- |
| **`H`** | `key.ocradditions.cursor` | Открывает экран курсора для клика по виджетам с `clickable = true` (Tier 2+). |
| **`G`** | `key.ocradditions.gaze` | Отправляет луч взгляда до 64 блоков: блок, сущность или промах (Tier 3). |

## Конфигурация

Файл `config/ocradditions-common.toml` создаётся NeoForge автоматически. Параметры по умолчанию из `Config.java`:

| Ключ | По умолчанию | Описание |
| :--- | :---: | :--- |
| `relativeCoordinates` | `true` | Использовать относительные координаты от моста/радара вместо мировых. |
| `defaultChatPrefix` | `"$$"` | Префикс чат-команд по умолчанию (1..16 символов без пробелов). |
| `maxRange` | `256` | Максимальная дистанция связи очков с мостом (`0` — без ограничения). |
| `allowCrossDimension` | `false` | Разрешить работу очков в другом измерении (требует `maxRange = 0` или того же измерения). |
| `requireEnergy` | `false` | Если `true`, очки требуют FE-энергию для работы и рендера. |
| `energyCapacity` | `100000` | Максимальный запас FE в очках. |
| `energyPerTick` | `5` | Расход FE за тик при активном подключении (`requireEnergy = true`). |
| `radarScanEnergyCost` | `0.0` | Расход энергии сети OpenComputers за один вызов `radar.scan()`. |
